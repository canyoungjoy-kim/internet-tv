아래 조건에 해당하는 예약된 세대의 담당 기사를 한 번에 지정합니다.
균등 분배는 등록된 기사 전원에게 호실 순서대로 고르게 나눕니다. 예를 들어 기사 3명에 30세대면 각 10세대씩, 층이 섞이지 않도록 앞에서부터 차례로 배정합니다.
이미 배정된 기사도 덮어씁니다. 특정 세대만 따로 바꾸려면 세대 상세에서 수정하세요.

입주민 예약함 점검
서버의 예약을 한 건씩 세대 목록과 대조합니다. 같은 세대에 예약이 두 건 있거나, 세대에 안 옮겨진 예약이 있으면 찾아내 정리할 수 있습니다. 예약을 받는 동안 가끔, 그리고 작업요청서를 뽑기 전에 한 번 눌러보세요.
자료 내보내기 / 가져오기
예약 개시 전 설치팀과의 사전회의에 쓰는 요약 문서를 새 창으로 만듭니다. 세대 현황 · 날짜별 시간대별 정원 · 필요 인력 · 장비 물량 · 호텔 세대 처리방법이 들어가고, 부록으로 입주민 예약페이지 주의사항 · 작업요청서 샘플 · 예약화면 예시(부재·비번) 가 붙습니다. 새 창에서 인쇄를 누르면 종이 또는 PDF로 저장됩니다.
개인정보(성명·연락처)는 들어가지 않습니다.
호텔 운영 호실처럼 여러 세대를 한꺼번에 지정할 때 쓰세요. 호실 목록을 붙여넣고 유형을 고른 뒤 적용을 누르면 됩니다.
엑셀에서 다른 이름으로 저장 → CSV UTF-8 로 저장한 파일을 올리세요.
첫 줄은 머리글로 봅니다. 열 이름에 호실/호수, 이름/성명, 연락처/전화, 비고 가 들어가면 자동으로 인식합니다.
같은 호실이 이미 있으면 이름·연락처만 덮어쓰고 예약·작업 상태는 유지합니다.

⚪ 미설정
Firebase 설정 후 Google 로그인하면 사무소·기사 폰에서 실시간으로 같이 봅니다.
Firebase 설정 열기 / 규칙 안내
이 앱은 기존 시설일지 앱과 완전히 별개로 돌아갑니다. 저장 위치·설정·캐시가 모두 분리되어 있어 서로 영향을 주지 않습니다. 새 Firebase 프로젝트를 따로 만드는 것을 권합니다. (같은 프로젝트를 써도 데이터는 섞이지 않지만, 교체작업이 끝난 뒤 프로젝트째 정리하기 편합니다.)
  1. Firebase 콘솔 → 프로젝트 추가 → 웹 앱 추가 → firebaseConfig 복사
  2. Authentication → 로그인 방법에서 Google 과 익명 을 둘 다 사용 설정
    (익명은 입주민 예약 페이지 본인확인에 씁니다)
  3. Firestore Database 만들기 → 규칙에 아래 내용을 통째로 붙여넣기

                
              

              

                
                
              

              
            

          

        

      


      

        
입주민 예약 페이지

        

          
입주민이 이 주소로 들어가 호실 + 연락처 뒷 4자리로 본인 확인 후 직접 시간을 고릅니다. 예약 즉시 이 앱에 반영됩니다.

          

            
            

              
              
            

          

          
          
접수를 닫으면 예약 페이지에서 "접수 마감" 안내가 나오고 새 예약이 들어오지 않습니다. 이미 확정된 예약은 그대로 유지됩니다.

          

          
          

            입주민 예약 페이지가 열리려면 GitHub의 internet-TV/fbconfig.js 파일에 접속 설정이 들어 있어야 합니다.
            위 버튼으로 내용을 복사해 GitHub에서 그 파일에 붙여넣고 저장(커밋)하세요. 최초 1회만 하면 됩니다.

시간대 설정

        

          

시간표는 A · B · C 세 벌뿐입니다. 위 작업일마다 그중 하나를 골라 쓰시면 됩니다.

            아무것도 안 고르면 월~금은 A · 토요일은 B · 일요일은 C 가 자동으로 잡힙니다.
          

          

          
정원은 그 시간대에 받을 수 있는 세대 수입니다. 기사 인원 × 시간당 처리 세대로 잡으세요. 정원이 차면 입주민 예약 페이지에서 그 시간대가 마감으로 표시됩니다.
