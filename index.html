Firebase 설정 열기 / 규칙 안내
이 앱은 기존 시설일지 앱과 완전히 별개로 돌아갑니다. 저장 위치·설정·캐시가 모두 분리되어 있어 서로 영향을 주지 않습니다. 새 Firebase 프로젝트를 따로 만드는 것을 권합니다. (같은 프로젝트를 써도 데이터는 섞이지 않지만, 교체작업이 끝난 뒤 프로젝트째 정리하기 편합니다.)
  1. Firebase 콘솔 → 프로젝트 추가 → 웹 앱 추가 → firebaseConfig 복사
  2. Authentication → 로그인 방법에서 Google 과 익명 을 둘 다 사용 설정
    (익명은 입주민 예약 페이지 본인확인에 씁니다)
  3. Firestore Database 만들기 → 규칙에 아래 내용을 통째로 붙여넣기

                
              

              

                
                
              

              
            

          

        

      


      

        
입주민 예약 페이지

        

          
입주민이 이 주소로 들어가 호실 + 연락처 뒷 4자리로 본인 확인 후 직접 시간을 고릅니다. 예약 즉시 이 앱에 반영됩니다.

          

            
            

              
              
            

          

          
          
접수를 닫으면 예약 페이지에서 "접수 마감" 안내가 나오고 새 예약이 들어오지 않습니다. 이미 확정된 예약은 그대로 유지됩니다.

          

          
          

            입주민 예약 페이지가 열리려면 GitHub의 internet-TV/fbconfig.js 파일에 접속 설정이 들어 있어야 합니다.
            위 버튼으로 내용을 복사해 GitHub에서 그 파일에 붙여넣고 저장(커밋)하세요. 최초 1회만 하면 됩니다.
